-- сайт-энкциклопедия по <<UnCiv>> --

!комментарий из дому! проект переделаю на django. Чтобы на flask и на django была практика по созданию проектов.

описание:
Свободная энкциклопедия по глобальной стратегии <<UnCiv>>.
Создана чтобы пользователи могли свободно размешать свои статьи по данной игре 
и обсуждение(комментирование) данных статей.

страницы:
    - Главная, на ней должна быть кратка информацию по игре, чтобы пользователи поняли о чём этот сайт
    - Страница поиска статьи
    - Страница статьи
    - Регистрация и Авторизация
    - Страница написание статьи
    - Пользовательские настройки // например чтобы непоказавались статьи которые непроверены администрации
    - Админ панель
    - и другие
